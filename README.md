# 🚀 OmniRegress

**Blazing-fast modern regression library in Python & Rust**

OmniRegress is your all-in-one toolkit for regression analysis, combining Python's flexibility with Rust's performance.

---

## 📁 Project Structure

```
OmniRegress_test/
├── LinearRegression/          # Linear regression implementations
│   ├── data/                 # Datasets
│   ├── main.py              # Main linear regression module
│   ├── pure_omni_housing.py # Housing price regression example
│   └── test_performance.py  # Performance testing
├── Test/                     # Test suite
└── main.py                  # Project entry point
```

## 🧪 Quick Start

### Run Linear Regression
```bash
cd LinearRegression
python main.py
```

### Run All Tests
```bash
python Test/run_tests.py
```

- 🏠 **Housing Price Prediction** - Real-world regression examples
- 📊 **Performance Optimized** - Fast execution with detailed metrics
